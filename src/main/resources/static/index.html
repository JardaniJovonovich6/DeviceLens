02 / PERMISSION BOUNDARIES

Access is a separate question.

These are permission states for this site, not a list of permissions for every website.

Queries only · no access requested

“Prompt” means permission would be needed; we never request it. “Denied” can result from your settings or this page’s security policy, which blocks location, camera and microphone access. Permission-query support varies by browser. Clipboard permission is queried without reading your clipboard.

03 / THE LIMITS

Some things stay out of view.

NOT EXPOSED BY THESE APIS

Private hardware identifiers

IMEI, device serial number, MAC address and your phone number are not available through the browser APIs this tool uses.

NOT ACCESSED

Location, camera & microphone

We query permission states, not sensor data. We do not request your coordinates, capture media, enumerate devices, or read files.

NOT RELIABLY DETECTABLE

VPN, private mode & identity

This inspection cannot reliably determine your VPN, private browsing mode, tracking protection, real name, or exact retail device model.

What about my IP address?

A website’s server sees a connection’s public IP when serving the page. JavaScript does not directly provide it. DeviceLens does not look up or display your IP, and application access logging is disabled. Hosting providers may retain infrastructure logs.

01

Language + timezone

Display + browser + hardware hints

A FEW IMPORTANT ANSWERS

Privacy, without the guesswork.

Why is my exact device model unavailable?

Many browsers do not expose a model, especially desktop browsers and Safari. Android Client Hints sometimes provide a model code. A generic “iPhone” family or a model code is not a verified retail model name. We leave unknown values unavailable.

Does an unavailable signal mean I am anonymous?

No. An unavailable value may reflect browser support, a denied query, or reduced data. Other information such as login accounts, IP addresses and ordinary HTTP headers can still identify or connect activity.

Are these values accurate hardware specifications?

They are browser-reported values or labeled inferences. Memory and network estimates are approximate. Screen dimensions use CSS pixels, which can differ from physical pixels. User-Agent strings and Client Hints can be reduced or spoofed.

What happens when I copy or download?

Your browser creates a report locally. Copy writes it to your clipboard only when you click Copy report. Download saves a JSON file on your device. DeviceLens does not upload either report. Treat the exported file as personal information if you share it yourself.

What does this tool deliberately avoid?

We do not generate a fingerprint hash, draw canvas or audio fingerprints, enumerate installed fonts or media devices, request geolocation, scan local networks, probe private mode, inspect files, or send results to an administrator.

How can I verify the local-only behavior?

Open your browser’s Network developer tools, reload this page and inspect the requests. You should see only this site’s page and static assets, with no report POSTs or third-party requests. The site’s Content Security Policy blocks script connections. Ordinary page requests still reach the hosting server.
